# HMI 布局规则

本文件定义布局安全、对齐、边界、元素避让、动态元素和 HTML 页面布局规则。

本文件不定义固定主题、颜色、字号、边距、间距、按钮尺寸或页面模板。所有尺寸、位置、颜色、字体、主题、布局风格和组件数量都可由用户明确指定；用户要求优先，但必须符合 `schema.md`。

## 1. 用户要求优先

- 用户明确指定画布、组件位置、组件尺寸、HTML 页面结构、颜色、字体、主题、排列方式或页面结构时，必须优先执行。
- 用户明确要求叠加时，仅当不遮挡关键交互、不造成文字不可读且 Schema 合法时允许。

## 2. 自动布局原则

用户未给出完整位置或尺寸时：

- 根据画布、组件数量、已验证默认尺寸、功能和文本长度动态安排。
- 先规划功能区域，再放置原生组件或 HTML 页面内容。
- 同功能组保持视觉相邻；同类组件优先对齐、尺寸一致、间距一致。
- 空间不足时，重新排列、拆分区域、减少非关键预览内容或使用 `node:tabView`；不得让普通元素重叠。
- 原生组件未指定样式时，仅使用已验证 JSON 示例或组件 Schema 中已有字段和值；不得强制额外主题方案。

## 3. 元素边界

- 所有原生组件包围盒必须在画布或合法父节点可用范围内。
- 对描边、文字、选中框、图片或视觉外扩内容，应避免紧贴画布边缘。
- 不得让关键文字、按钮、输入、输出、图表、仪表、表格或工艺图形被裁剪。
- 用户明确靠边布局时，组件本体和关键文字仍须可见。

## 4. 普通组件不得重叠

除合法工艺重叠外，按钮、开关、复选框、输入、输出、选择器、滑动条、文字、标签、仪表、图表、表格以及不属于同一复合工艺对象的基础图形之间不得发生包围盒交叉。

- 文字不覆盖控件、仪表、图表或表格。
- 两个交互组件不相交。
- 标签、读数、单位文字不互相覆盖。
- 不同功能区普通组件不相交。
- 容器背景或边框不遮挡其视觉区域上的组件。

## 5. 合法工艺重叠

下列具有明确工艺语义的重叠允许存在：滚筒位于输送带两端；流动虚线位于输送带、管道或工艺路径上；液面在水箱或储罐轮廓内部；阀门、泵、电机等由多个基础图形组成；状态灯或局部标签紧邻设备；根级容器作为底层背景。

合法重叠必须表达设备结构、工艺介质、流向、状态或层次关系；关键控制与关键文字仍需可见、可读、可操作。层级应保持背景/外壳在前、介质/路径居中、状态/文字在后。

## 6. 分组与对齐

- 同一控制组的按钮、开关、输入与输出优先对齐。
- 相同功能组件优先使用一致尺寸，除非用户明确不同。
- 标签、读数与单位保持清晰对应和合理对齐。
- 状态灯与状态文字形成清晰相邻关系。
- 用户要求并排、上下、居中、靠左、靠右、顶部或底部时，按其语义排列。

## 7. 容器和页签

- `node:container` 仅作根级背景、边框或视觉分区。
- 普通组件不能放入 `node:container.children`，必须与容器并列放在 `graph.children`。
- 容器必须先于覆盖其区域的组件出现，以确保其作为底层背景。
- 信息无法在同一画布清晰呈现时，可使用 `node:tabView`。

## 8. HTML 页面布局

- `graph.htmlCode` 本身没有原生位置和尺寸字段；HTML 页面应通过标准 HTML/CSS 布局适配画布可见区域。
- 完整 HTML 文档或头部/正文片段均可按渲染器已验证方式生成；CSS 通常在 `<head>` 的 `<style>` 中，页面结构和脚本通常在 `<body>` 中。
- HTML 可见内容不得超出画布、产生无意义水平滚动、遮挡关键原生控件或破坏用户指定布局。
- 原生组件与 HTML 混合仅在层级关系已验证时使用；未验证时，选择一种实现路径，不要默认叠加。
- HTML 内部可以使用合理嵌套、卡片、网格、表格、表单和局部视觉重叠，但关键文字、按钮、读数须可见、可操作。
- iframe 宽高和页面内容应适配可用画布；目标网站加载失败或拒绝嵌入时，不得视为布局成功。
- HTML 的动画、图表、脚本更新和外部库渲染在任何状态下均不得裁剪关键内容或覆盖关键控制。

## 9. 动态元素布局

- 动态组件在所有可见状态下不得超出画布、遮挡关键文字或覆盖其他普通组件。
- 流动路径、液面、旋转标识和状态强调可与所属工艺对象合法重叠，但不得覆盖关键控制、关键读数或报警文字。
- 为动态文字、数值变化与状态切换预留空间。
- 背景、工艺主体、动态介质/路径、状态标识与文字应具有清晰层级。

## 10. 输出前布局检查

1. 用户明确要求的尺寸、位置、主题、HTML 和布局已优先执行。
2. 所有原生组件和 HTML 可见内容均在画布或合法父节点范围内。
3. 普通组件之间不存在包围盒交叉。
4. 所有文字可读，未被控件、HTML、图表、仪表或画布边界遮挡。
5. 合法重叠仅用于工艺复合图形、流向、液面、状态标识或容器背景。
6. 动态元素在全部状态下不越界、不裁剪、不遮挡关键文字、读数或控制。
7. HTML 页面内容适配画布，且在已验证混合场景中未遮挡关键原生控件。
8. 同组组件保持合理对齐与顺序。
9. 空间不足时已重新布局、分组或使用页签，而不是制造重叠。
10. 所有布局结果严格符合 `schema.md`。
